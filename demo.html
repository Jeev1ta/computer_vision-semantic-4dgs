🔬 Multi-View 2D→3D Semantic Label Transfer

Complementary geometric pipeline from semantic-3d-gaussian-splatting: projects 3D Gaussian centers into calibrated 2D camera views, looks up SAM 2 masks, and aggregates per-Gaussian labels via multi-view voting.

Core Algorithm
  1. For every trained Gaussian center X_world, project into each calibrated camera's image plane
  2. If projected pixel falls inside an object mask → cast a vote for that object ID
  3. Aggregate votes via: single-view / majority / confidence-weighted strategy
  4. Assign winning label per Gaussian, or -1 (unknown) if insufficient agreement
Baseline A
Single-view lifting
(n_views = 1)
Baseline B
Majority voting
(equal weights)
Proposed
Confidence-weighted
(mask score × dist × scale)

🔬 Mathematical & Geometric Foundations of 3D Splat Re-Orientation
1. 2D ➔ 3D Lifting Inverse Projection
Each image pixel \((u, v)\) inside an object mask is back-projected through the camera intrinsics matrix: \[ x = \frac{(u - c_x) \cdot z}{f}, \quad y = -\frac{(v - c_y) \cdot z}{f} \] Depth \(z\) is recovered from monocular perspective priors (vertical positioning + area coverage).
2. Centroid-Relative SO(3) Rotation
When you rotate an object (e.g. the sofa), its 3D Gaussian centers \(x_i\) rotate around the object's local bounding centroid \(c\): \[ x_i' = R(\theta_x, \theta_y, \theta_z) \cdot (x_i - c) \cdot S + c + t \] guaranteeing rigid shape preservation without shearing or distortion.
3. Gaussian Covariance Transformation
Each 3D Gaussian's anisotropic covariance matrix \(\Sigma_i\) is dynamically rotated with the object: \[ \Sigma_i' = R \cdot \Sigma_i \cdot R^T \] allowing realistic specular highlights and view-dependent opacity from any orbit angle.
