🔬 Multi-View 2D→3D Semantic Label Transfer

Complementary geometric pipeline from semantic-3d-gaussian-splatting: projects 3D Gaussian centers into calibrated 2D camera views, looks up SAM 2 masks, and aggregates per-Gaussian labels via multi-view voting.

Core Algorithm
  1. For every trained Gaussian center X_world, project into each calibrated camera's image plane
  2. If projected pixel falls inside an object mask → cast a vote for that object ID
  3. Aggregate votes via: single-view / majority / confidence-weighted strategy
  4. Assign winning label per Gaussian, or -1 (unknown) if insufficient agreement
Baseline A
Single-view lifting
(n_views = 1)
Baseline B
Majority voting
(equal weights)
Proposed
Confidence-weighted
(mask score × dist × scale)

⚖️ Dual-Pathway Semantic Architecture: Gradient-Based vs Geometric Projection
Property Gradient-Based (Main Pipeline) Geometric Projection (Multi-View Voting)
Approach Learnable semantic vector per Gaussian, trained jointly with RGB Project 3D centers into 2D masks, aggregate votes across views
Scene Type Dynamic (4D-GS + HexPlane temporal deformation) Static (3D-GS, calibrated multi-view)
Supervision SAM 2 + CLIP distillation → differentiable loss SAM 2 masks → hard label voting
GPU Required Yes (CUDA rasterizer) No (CPU-only)
Key Advantage Handles motion, temporal consistency, open-vocabulary CLIP features No training required, interpretable voting, built-in ablation
